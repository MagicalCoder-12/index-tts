                          RELEASE PREPARATION

To create your first release on GitHub:

1. Commit all changes:
   $ git add .
   $ git commit -m "chore: clean repository structure and add release documentation"

2. Create a release tag:
   $ git tag -a v2.0.0 -m "IndexTTS2 Release v2.0.0"

3. Push to GitHub:
   $ git push origin main
   $ git push origin v2.0.0

4. The GitHub Actions workflow will automatically:
   ✓ Create a GitHub Release
   ✓ Generate release notes
   ✓ Build source distributions
   ✓ Upload artifacts to releases page

5. Users can then install via:
   $ pip install -U uv
   $ git clone https://github.com/index-tts/index-tts.git
   $ cd index-tts
   $ git checkout v2.0.0
   $ git lfs pull
   $ uv sync --all-extras

# Telugu TTS Training - Quick Reference

## 30-Second Setup
```bash
cd \"d:\\Voice Cloner\\index-tts\"
python train_telugu.py
```

## Start Training (1 GPU)
```bash
python -m torch.distributed.launch --nproc_per_node=1 \\n  indextts/train.py --config checkpoints/config_telugu.json \\n  --exp_name telugu_voice_v1
```

## Start Training (2 GPUs)
```bash
torchrun --nproc_per_node=2 \\n  indextts/train.py --config checkpoints/config_telugu.json \\n  --exp_name telugu_voice_v1
```

## Monitor Training
```bash
tensorboard --logdir exp_results/telugu_voice_v1/log
```
Then visit: http://localhost:6006

## Key Files
- **train_telugu.py** - Prepare configuration
- **checkpoints/config_telugu.json** - Training config (generated)
- **tests/te/wav_clips/** - 119 Telugu samples
- **TELUGU_TRAINING_GUIDE.md** - Full documentation

## Configuration
```json
{
  \"dataset\": \"tests/te/wav_clips\",
  \"batch_size\": 4,
  \"max_epoch\": 50,
  \"learning_rate\": 1e-4,
  \"sr\": 24000,
  \"n_mels\": 100
}
```

## Customize Batch Size
For 16GB GPU: Set batch_size to 8 in config_telugu.json
For 24GB GPU: Set batch_size to 12 in config_telugu.json

## Dataset Stats
- 119 Telugu voice samples
- 24000 Hz sample rate
- 3-10 seconds duration
- Complete metadata with text
- 90/10 train/validation split

✓ Full Telugu language support

## Common Issues

**Out of Memory:**
Reduce batch_size to 2 or 1

**Slow Training:**
Ensure GPU is being used: nvidia-smi

**Missing Config:**
Run: python train_telugu.py

**Dataset Error:**
Verify all 119 files exist in tests/te/wav_clips/

## After Training
Checkpoints saved to: exp_results/telugu_voice_v1/checkpoint/

Use for voice cloning:
```bash
python clone_telugu_voice.py --voice <sample.wav> \\n  --text \"తెలుగు\" --checkpoint <path>
```

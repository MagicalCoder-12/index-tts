## Quick Start Guide

### Step 1: Prepare Training Configuration
```bash
cd \"d:\\Voice Cloner\\index-tts\"
python train_telugu.py
```

This generates: `checkpoints/config_telugu.json`

### Step 2: Start Training (Single GPU)
```bash
python -m torch.distributed.launch --nproc_per_node=1 \\n  indextts/train.py \\n  --config checkpoints/config_telugu.json \\n  --exp_name telugu_voice_v1
```

### Step 3: Start Training (Multi-GPU)
```bash
torchrun --nproc_per_node=2 \\n  indextts/train.py \\n  --config checkpoints/config_telugu.json \\n  --exp_name telugu_voice_v1
```

### Step 4: Monitor Progress
```bash
tensorboard --logdir exp_results/telugu_voice_v1/log
```

Then open: http://localhost:6006

## Training Architecture

The model uses FAcodec with:
- **Encoder**: Compresses audio into latent space
- **Quantizer**: Quantizes with learnable codebook
- **Decoder**: Reconstructs high-quality audio
- **Discriminator**: Adversarial training for quality
- **Predictors**: 
  - Pitch/F0 prediction for prosody
  - Voicing detection
  - Phonetic content extraction
  - Speaker timbre preservation

## Troubleshooting

**Q: \"Dataset not found\" error**
A: Ensure all 119 WAV files are in `tests/te/wav_clips/`

**Q: \"Out of memory\" error**
A: Reduce batch_size to 2 or 1 in config_telugu.json

**Q: Training is slow**
A: Check GPU usage with: `nvidia-smi`
   If CPU-bound, reduce num_worker to 2

**Q: Missing dependencies**
A: Install: `pip install accelerate librosa tensorboard`
